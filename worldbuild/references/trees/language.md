# Language / Script

WA source: `language.html.twig`.

## Infobox fields

Shared Name/Status plus: **Alphabet/script** (or note if unwritten), **Geographic distribution**, **Speaker ethnicities/cultures** (relation, fact-find first).

## Document sections (prose body)

**Phonology & Phonetics** (what it sounds like — even a rough description helps a writer stay consistent when rendering dialogue or names), **Morphology & Syntax** (only as deep as actually useful for a novel — most fiction needs flavor, not a full grammar), **Naming Conventions** (male/female/unisex name patterns — if this overlaps heavily with an associated Culture note's own Naming Conventions section, link rather than duplicate), **Vocabulary Highlights** (a handful of notable words/concepts that don't translate cleanly, useful for peppering into dialogue), **Common Phrases**, **History & Spread**.
