## Infobox fields

Shared Name/Status plus: **School/Discipline** (relation to the parent Magic system, if one exists, fact-find first), **Element**, **Level/Tier** (if the system is tiered), **Casting time**, **Duration**, **Range**, **Source** (the specific deity, tradition, or technique line this comes from, if narrower than the whole Magic system).

## Document sections (prose body)

**Effect** (what it does), **Requirements** (material components, gestures, and verbal elements. Make specific whatever general shape the parent system's Access/Cost branch established), **Side Effects/Risks**, **Discovery/Origin** (who first developed or discovered it, if known), **Restrictions** (who is permitted to learn or use it, with a relation to a Faction that controls access, if applicable).
