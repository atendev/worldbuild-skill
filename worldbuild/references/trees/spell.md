# Spell / Technique

WA source: `spell.html.twig`.

## Infobox fields

Shared Name/Status plus: **School/Discipline** (relation to the parent Magic system, if one exists — fact-find first), **Element**, **Level/Tier** (if the system is tiered), **Casting time**, **Duration**, **Range**, **Source** (the specific deity, tradition, or technique-line this derives from, if narrower than the whole Magic system).

## Document sections (prose body)

**Effect** (what it actually does), **Requirements** (material components, gestures, verbal elements — whatever the parent system's Access/Cost branch established as the general shape, made specific here), **Side Effects/Risks**, **Discovery/Origin** (who first developed or discovered it, if known), **Restrictions** (who's permitted to learn or use it — relation to a Faction that gatekeeps it, if applicable).
