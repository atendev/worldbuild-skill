# Calendar / Timekeeping System

No WA source — hand-drafted.

## Infobox fields

Shared Name/Status plus: **Year length**, **Month count**, **Week structure** (if the setting has an equivalent), **Current reference year/era** (fact-find against Event notes for an epoch this counts from).

## Branches

- What natural phenomena, if any, does timekeeping derive from — one or more suns/moons, seasons, something else entirely (an artificial or magical cycle)?
- How is a single day itself divided — hours, named periods (dawn/noon/dusk-style blocks), something else? No WA source touches this at all; it's easy to default to real-world hours without deciding whether that's actually right for the setting.
- Do multiple cultures in the setting use different calendars, and if so, is there a common "converted" reference point writers should default to for consistency? (Fact-find against Culture notes first.)
- Is there a specific epoch/founding event this calendar counts from (Year 0, a founding, a cataclysm)? (Fact-find against Event notes.)

## Document sections (prose body)

**Structure** (months, days, weeks — however the setting divides time), **Day Divisions** (hours or named periods within a single day), **Astronomical Basis**, **Notable Epochs/Eras** (link to Event notes rather than re-describing them), **Cultural Variations** (if more than one calendar system coexists in the setting).
