# Calendar / Timekeeping System

No WA source. Hand-drafted.

## Infobox fields

Shared Name/Status plus: **Year length**, **Month count**, **Week structure** if the setting has an equivalent, and **Current reference year/era**, which you should fact-find against Event notes for an epoch this counts from.

## Branches

- What natural phenomena, if any, does timekeeping derive from? Examples are one or more suns or moons, seasons, or something else entirely, such as an artificial or magical cycle.
- How is a single day divided? Options include hours, named periods such as dawn, noon, and dusk blocks, or something else. No WA source covers this. It is easy to default to real-world hours without deciding whether that suits the setting.
- Do multiple cultures in the setting use different calendars, and if so, is there a common "converted" reference point writers should default to for consistency? Fact-find against Culture notes first.
- Is there a specific epoch or founding event this calendar counts from, such as Year 0, a founding, or a cataclysm? Fact-find against Event notes.

## Document sections (prose body)

**Structure**, covering months, days, and weeks, however the setting divides time. **Day Divisions**, covering hours or named periods within a single day. **Astronomical Basis**. **Notable Epochs/Eras**, linking to Event notes rather than re-describing them. **Cultural Variations**, only if more than one calendar system coexists in the setting.
