# Style / Tone Guide (meta)

This is the formal version of the "formatting/style guide document" that SKILL.md Step 6 already lets a user point the skill at. It is a standing reference, not a one-off pointer file.

## Questions

- Prose conventions: sentence rhythm, vocabulary register, and any words or phrases to avoid or favor.
- Terminology conventions: capitalization rules for invented terms, preferred spelling of setting-specific words, and how the notes should refer to time and measurement. Does the setting use real-world units or invented ones?
- Voice: is there a consistent narrative distance or tone the user wants the worldbuilding notes written in, such as clinical wiki style or immersive in-world voice? This is separate from the eventual manuscript's own prose style.

## Synthesis approach

Compile from examples the user provides, such as existing notes whose tone they like or manuscript excerpts. Do not invent conventions from nothing. Once built, this file is what Step 6 reads when the user tells future interviews to "use my style guide" instead of pointing at a one-off document.
