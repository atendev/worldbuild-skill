# Style / Tone Guide (meta)

This is the formalized version of the "formatting/style guide document" SKILL.md Step 6 already lets a user point the skill at — as a standing reference rather than a one-off pointer file.

## Questions

- Prose conventions — sentence rhythm, vocabulary register, any words/phrases to avoid or favor.
- Terminology conventions — capitalization rules for invented terms, preferred spelling of setting-specific words, how the notes should refer to time/measurement (does the setting use real-world units or invented ones).
- Voice — is there a consistent narrative distance/tone the user wants worldbuilding notes themselves written in (clinical wiki-style versus immersive in-world voice), independent of the eventual manuscript's own prose style?

## Synthesis approach

Compile from examples the user provides (existing notes they like the tone of, or manuscript excerpts) rather than inventing conventions from nothing. Once built, this file is what Step 6 reads when the user points future interviews at "use my style guide" instead of a one-off document.
